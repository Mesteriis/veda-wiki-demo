# Writing pages

## Structure

Start with one `# Title`, then a short paragraph that says what the page is
for. Use `##` sections in the order a reader needs them; the table of contents
is built from headings.

## Names and links

File names are lowercase and hyphenated, and they stay stable: links and
history depend on them. Link within the repository with relative paths, such
as [the formatting page](formatting.md) or [the start page](../README.md);
a link that leaves the repository is removed.

## Keeping pages current

Replace outdated facts instead of appending contradicting ones, and say when
something was last checked if it can drift.[^drift]

[^drift]: For example: "Checked 2026-11-06 against the running service."
