# Rules for agents

- Read this file and the `AGENTS.md` of the directory you edit before writing.
- Find the existing page with `veda_find` or `veda_search` and update it; do not
  create near-duplicates.
- Write with `veda_write_article` and the `expected_revision` you read; on a
  conflict, reread and merge. Fix every returned `warnings` entry.
- Follow the formatting rules from `veda_format_guide`; the
  [formatting page](guides/formatting.md) shows each construct.
- Link every new page from its directory `README.md`.
- Record durable knowledge, not logs. Never write secrets: write where a secret
  is kept, not its value.
- Language: English.
